# 🛡️ CyberChat - Threat Intelligence Trainer

Chatbot éducatif interactif sur la **Threat Intelligence** et la **Cybersécurité générale**.

## 📚 Modules inclus
1. Introduction à la Cybersécurité (CIA Triad, types de menaces)
2. Threat Intelligence - Fondamentaux (IOC, TTPs, Cycle du renseignement)
3. Frameworks & Standards (MITRE ATT&CK, Kill Chain, Diamond Model)
4. Sources de Threat Intelligence (OSINT, Shodan, VirusTotal)
5. Analyse des Menaces (Malware analysis, SIEM, Threat Hunting)
6. Outils TI (Maltego, TheHive, MISP, YARA)
7. Réponse aux Incidents (PICERL, forensics, playbooks)
8. Certifications & Carrière (CEH, GCTI, parcours carrière)

## 🚀 Utilisation
Ouvre `index.html` dans ton navigateur. Aucune installation requise.

## ⌨️ Commandes
- `/module [1-8]` → accéder à un module
- `/quiz [1-8]` → quiz interactif
- `/glossaire` → dictionnaire des termes
- `/outils` → liste des outils professionnels

## 🎨 Fonctionnalités
- Interface dark theme style hacker
- Quiz interactifs par module
- Barre de progression
- Tip de sécurité du jour
